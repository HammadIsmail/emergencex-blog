# emergencex-blog

# پیچیدگی اور ایجنٹ بیسڈ ماڈلنگ (Complexity & Agent-Based Modeling)

> علمی و تحقیقی نگارشات از **ڈاکٹر محمد یاسر**  
> چیئرمین شعبہ کمپیوٹر سائنس | ڈائریکٹر **EmergenceX: Interdisciplinary Complexity Science Lab**  
> یونیورسٹی آف انجینئرنگ اینڈ ٹیکنالوجی (UET) لاہور، فیصل آباد کیمپس  

ایک جدید، تیز رفتار اور باوقار دو لسانی (اردو / انگریزی) تعلیمی پلیٹ فارم جو سسٹمز تھنکنگ، ایمرجنس (Emergence)، فیڈبیک لوپس اور ایجنٹ بیسڈ کمپیوٹیشنل ماڈلنگ کے موضوعات پر مبنی ہے۔

---

## 📚 شامل لیکچرز (Lectures Included)

1. **لیکچر 01:** ہجوم میں ہر فرد اپنی راہ خود تلاش کرتا ہے (Crowd Dynamics, Hajj & Kumbh Mela)
2. **لیکچر 02:** فرد قائم ربطِ ملت سے ہے، تنہا کچھ نہیں (Flocking, Self-Organization & Allama Iqbal)
3. **لیکچر 03:** ہر مشکل نظام Complex نہیں ہوتا (Complicated vs. Complex: Boeing 747 vs. Geese)
4. **لیکچر 04:** پیچیدگی اور ایجنٹ بیسڈ ماڈلنگ (Analytical Boundary & Perspective Shift)
5. **لیکچر 05:** ایجنٹ بیسڈ ماڈلنگ (ABM) کی بنیادیں اور اطلاقات (Micro-rules to Macro-patterns)
6. **لیکچر 06:** کیا ایک خلیے کے رویّے سے پورے ٹیومر کی کہانی سمجھی جا سکتی ہے؟ (Computational Oncology)
7. **لیکچر 07:** نتیجہ ہمیشہ کہانی کا اختتام نہیں ہوتا (Reinforcing Feedback Dynamics)
8. **لیکچر 08:** مسلسل بڑھتی ہوئی تبدیلی کو کیسے روکیں؟ (Balancing Feedback Loops & Desired State)
9. **لیکچر 09:** اب ہم سسٹمز کو کمپیوٹر میں ماڈل اور تجربہ کریں گے (Traffic Waves & Computational Thinking)
10. **لیکچر 10:** ایجنٹ بیسڈ ماڈلنگ شروع کرنی ہے—لیکن کس Tool سے؟ (NetLogo, Mesa, GAMA, Repast, AnyLogic)

## 🛠️ ٹیکنالوجی اسٹیک (Tech Stack)

- **Frontend Architecture:** Component-based dynamic rendering via [HTMX](https://htmx.org/)
- **Bundler & Dev Server:** [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Typography:** Google Fonts (`Noto Nastaliq Urdu`, `Newsreader`, `Plus Jakarta Sans`, `JetBrains Mono`)
- **Icons:** [Lucide Icons](https://lucide.dev/)

## 🚀 مقامی طور پر چلانے کا طریقہ (Quick Start)

```bash
# ریپازیٹری کلون کریں
git clone https://github.com/HammadIsmail/emergencex-blog.git

# پروجیکٹ ڈائریکٹری میں جائیں
cd emergencex-blog

# انحصار (Dependencies) انسٹال کریں
npm install

# لوکل ڈیولپمنٹ سرور چلائیں
npm run dev

# پروڈکشن بلڈ بنائیں
npm run build
```
